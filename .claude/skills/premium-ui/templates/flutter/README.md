# Flutter templates (proven in Softbound, 2026-11)

Drop-in, app-agnostic Dart files distilled from the Softbound Android app (2.5D notes shelf, Impeller, 120Hz). Copy `lib/kit/` into your app's `lib/kit/` and `test/` into your `test/`. In `kit_example_test.dart`, replace `your_app` with your package name. Dependencies: `vector_math` (all 3D files) and `audioplayers ^6.5` (only `sfx_pool.dart`).
Every file opens with a header covering what it does, when to use it, and the device lesson behind it. Constants are parameters, and the colours inside are only blend identities (marked `// lint-ok`). Put your own values in `lib/theme/tokens.dart`.
Verified on 2026-11-08: `flutter analyze` is clean, and `kit_example_test.dart` passes (render, leak, GPU-cost and unit checks) in a fresh package on Flutter 3.38.

| File | What | Use when | Device lesson baked in |
|-|-|-|-|
| `lib/kit/perf_log.dart` | Opt-in `PERF_LOG` frame logger: build/raster p50/p90/max, jank count, `transientCallbackCount`, your state string. Also `perfHide(layer)` for GPU bisecting | Every app with custom rendering | Raster (GPU) is the killer and tests can't see it. A climbing `transient` count means a leaked ticker |
| `lib/kit/sfx_pool.dart` | audioplayers in lowLatency mode, your own round-robin pool, a no-op PositionUpdater, no audio focus | Any overlapping SFX | MediaPlayer mode crashed. The FramePositionUpdater leaked one frame callback per play until the app froze. Music was paused |
| `lib/kit/world_clock.dart` | `WorldClock`: one sleeping Ticker with `onTick`/`wake`/`detach`. `ViewSwitcher`: exit, then enter, latest request queued | Many animated layers or views over one scene | Idle has to be zero frames. Taps made mid-transition were dropped |
| `lib/kit/cam25d.dart` | Perspective camera: `project`, `depth`, `plane()` (z flattened for hit-testing), `planeHomography` | Real 3D placement drawn with painters and widgets | A projective Transform broke `globalToLocal`, so the caret always jumped to 0 |
| `lib/kit/baked_face.dart` | `BakedSolid`: an object built from baked faces, culled, depth-sorted, Lambert-shaded, painted in one picture. It can hold a live widget on one face | Books, boxes, cards, anything that turns or opens | Shelf spin raster p50 was ~5ms at every time of day. Perspective defeats the raster cache |
| `lib/kit/vertex_tint.dart` | `drawTinted` (vertex-colour modulate), `drawFan`, `clipConvex`, `imageShaderOf`, `debugOnFan` | Any tint, shade, fog, cut or gobo band on many draws | A ColorFilter made night 2x the GPU cost. Catalogue raster went from 28–40ms to 1.6ms |
| `lib/kit/image_lifetime.dart` | `bakeAsync`/`bakeSync`, `Bake` (dispose is idempotent), `ImageRetirer` (~250ms delay), `BakeSlot` (one bake in flight, latest wins) | Baked art that changes at runtime | `toImageSync` during motion stalls the GPU. A disposed image draws as nothing on Impeller (flicker) |
| `lib/kit/live_relight.dart` | `Relight<L>`: blends the light model (direction nlerp, intensity in stops) and decides live vs bake | Theme or time-of-day switches that should move the light | Cross-fading two bakes reads as a dissolve. Live rendering is only for the 1.2s sweep |
| `lib/kit/low_rate_effect.dart` | Timer-driven ~30Hz repaint through a ValueNotifier, its own clock, `shouldRun` gate, optional cap | Living covers, dust, glows, anything that moves at rest | Idle was 30fps from the living cover and nothing else. Its repaint leaked into the shadows until it got a RepaintBoundary |
| `lib/kit/inactive_view.dart` | `IgnorePointer` + `ExcludeSemantics` for layered views | Several full-screen views stacked in one Stack | A leftover full-screen Listener swallowed every touch after leaving the catalogue |
| `lib/kit/spin_physics.dart` | `Spr` spring, `DetentSpin` (momentum, friction, magnetic detents, `onDetent`), `coast`, `rubberBand`, `wrapSlots` | Turntables, carousels, drawers, piles | Ported 1:1 from the web prototype so the feel matches |
| `lib/kit/verlet_chain.dart` | A 2D Verlet chain: pinned head, a finger can hold the tail, slack but never stretched, wind, settles. Plus `pullFeed` resistance | Pull cords, bookmarks, tassels | 2 substeps × 28 iterations costs almost nothing on the CPU. It unsubscribes once settled |
| `lib/kit/shadow_mesh.dart` | Soft cast shadow, ambient pool and contact line for many objects as one `drawVertices` (modulate) | Objects standing on a floor under a moving light | No blur. Books floated until they had all three shadows |
| `test/render_test_helper.dart` | `Render.boot/shot/run/strip/drag`: PNGs of the real screen inside `flutter test` | Every UI change and every regression test | Captures need `runAsync`. Never await an animating call before pumping |
| `test/gpu_cost_canvas.dart` | `CountCanvas`: counts advanced blends, colour filters, saveLayers, blurs, clips and fill area for one frame | Heavy painters (scroll lists, 2.5D scenes) | Tests can't time the GPU but can count what makes it slow |
| `test/kit_example_test.dart` | A small scene built from the kit, plus a leak test (switch views, then `transientCallbackCount <= 1` and the clock asleep), a GPU-cost assert, PNGs and unit checks | A starting point for your own regression suite | On the phone, 240+ leaked callbacks froze the app |
